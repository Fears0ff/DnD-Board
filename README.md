# DnD Board

Общее игровое поле для D&D-группы в локальной сети: мастер и игроки видят одну доску с токенами, перемещения синхронизируются в реальном времени через WebSocket, аутентификация — логин/пароль с серверной сессией.

## Быстрый старт

```bash
npm install
cp .env.example .env   # задайте APP_SECRET
npm run dev            # Vite dev server (frontend + backend на :3000)
```

Первый зарегистрированный пользователь автоматически становится **мастером**, остальные — **игроками**. Мастер может менять роли в диалоге «Люди».

## Скрипты

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Dev-режим: Vite + Hono/tRPC + WS-хаб |
| `npm run build` | Клиент в `dist/public`, сервер-бандл в `dist/boot.js` (better-sqlite3 копируется в `dist/node_modules`) |
| `npm start` | Production-запуск собранного бандла |
| `npm run check` | Строгая типизация (`tsc -b`) |
| `npm run test:integration` | Интеграционные тесты API/БД/WS (vitest) |
| `npm run test:e2e` | E2E-сценарий (Playwright, поднимает собранный сервер) |
| `npm run db:generate` | Генерация SQL из `db/schema.ts` (drizzle-kit) |

## Архитектура

- **`contracts/`** — общие клиент-серверные типы, zod-схемы и константы (единственный источник правды по DTO).
- **`api/`** — Hono + tRPC: `routers/` тонкие, транзакции и инварианты в `services/`, SQL только в `repositories/`.
- **`db/`** — better-sqlite3 + Drizzle; миграции встроены в бандл (`db/migrations/*.ts`) и применяются транзакционно при старте.
- **`api/realtime/hub.ts`** — WS-хаб `/ws`: только уведомления `game.changed` с ревизией; мутации — исключительно через tRPC.
- **`src/`** — React 19 + Tailwind + shadcn/ui; доска рисуется на canvas (`BoardCanvas`).

### Синхронизация состояния

1. Каждая мутация меняет данные и инкрементирует `game_revision` **в одной транзакции**.
2. После коммита сервер рассылает `game.changed { revision }` по WS.
3. Клиент инвалидирует снимок `game.state`; сообщения со старой ревизией игнорируются.
4. Пока WS не открыт — polling каждые 4 с; после восстановления WS — полный refetch.

### Права

- Мастер: доски, токены (создание/редактирование/удаление), инициатива, роли.
- Игрок: может двигать **только свой** токен (`tokens.move`), проверка на сервере.
- Последний мастер защищён от понижения транзакционно.
